# Use Drizzle with better-sqlite3

Foundry uses stable Drizzle ORM with `better-sqlite3` for its unified local database. Although this adds a native dependency and packaging cost compared with Node's built-in SQLite API, Foundry expects persistence to expand across Prompts, Skills, MCP Servers, Agents, and their query workflows; stable schema definitions, typed queries, and migration tooling justify that cost, while the release-candidate Drizzle driver for `node:sqlite` is not accepted for the persistence foundation. Drizzle Kit's generated SQL migrations and journal are committed as immutable source assets and copied into the published `dist/migrations` directory; both new and existing databases execute every pending migration in order rather than initializing from a separately maintained schema snapshot.
