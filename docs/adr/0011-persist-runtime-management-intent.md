# Persist Runtime management intent independently of configuration files

Foundry stores one record for each supported Runtime with a `managed` flag, an optional Provider reference, and the most recent successful application time. An unmanaged Runtime has `managed = false` and no Provider reference; a Managed Runtime targets a saved Provider when the reference is present and the virtual Official Default when it is absent. This state represents Foundry's management intent rather than a mirror of the Runtime's current configuration: edits made outside Foundry do not change the Runtime Assignment, and configuration readability or drift is not persisted. Inferring assignment from configuration files was rejected because external edits, duplicate Provider configurations, and unreadable files would make Foundry's management state ambiguous.
