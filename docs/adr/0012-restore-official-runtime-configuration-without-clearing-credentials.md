# Restore official Runtime configuration without clearing credentials

Restoring Official Default removes only the active model, Provider selection, endpoint, and authentication override fields that Foundry owns in the Runtime's user-level configuration. Codex Provider tables are retained but no longer selected so Codex session discovery can continue using the stable Provider key; Claude Code removes every Foundry-owned field from its `env` object while preserving unrelated entries. Foundry preserves the configuration file, Codex and Claude Code credential files, operating-system credential stores, shell and cloud credentials, and account-policy fields; the Runtime therefore reuses an existing official login or presents its own official login flow when no valid credential exists. Clearing credentials or invoking Runtime logout was rejected because Provider selection and account authentication are separate concerns.
