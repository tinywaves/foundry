# Store Provider API keys in the Foundry database

Foundry stores user-entered Provider API keys unencrypted in `foundry.sqlite` alongside the rest of the Provider configuration, consistent with the single-database decision in ADR 0005 and the Local Web UI's single-user, loopback-only boundary. Provider APIs may return the complete key so it can be viewed and edited locally; the UI masks it by default and exposes an explicit show-or-hide control, but Foundry does not attempt to isolate it from other processes running as the same operating-system user. Database backups therefore also contain Provider API keys; operating-system credential stores and environment-variable-only references were rejected to keep Provider configuration self-contained and portable within Foundry's existing persistence model.
