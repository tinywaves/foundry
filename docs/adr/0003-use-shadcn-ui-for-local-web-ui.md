# Use shadcn/ui for the Local Web UI

The Local Web UI uses shadcn/ui with the Base UI foundation, Mira style, and neutral base color. This combination provides a compact, visually neutral Sidebar and mobile navigation without adopting the larger default sizing or blue emphasis of the other evaluated component libraries. Foundry accepts Tailwind CSS and project-owned generated component source in exchange for direct control over density and styling; generated components should retain the selected shadcn default theme unless a later product design decision changes it.
